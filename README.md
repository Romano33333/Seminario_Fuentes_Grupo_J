# Seminario_Fuentes_Grupo_J
## 1. Preparación de los datos de fumadores

En esta sección realizamos el proceso de limpieza y actualización de los datos asociados a la población fumadora por comunidad autónoma.  
Inicialmente, la carpeta `INPUT/DATA/Fumadores/` contenía una serie de archivos en formato JSON descargados de la misma fuente y con uan estructura muy compleja, además de tener años incomplementarios con los de criminalidad. 
Debido a esto, se decidió sustituirlos por un conjunto de archivos **CSV** con una estructura mejor, correspondientes al periodo hasta **2023**, proporcionados por una fuente oficial.

A continuación, eliminamos los archivos JSON antiguos y copiamos los nuevos CSV dentro de la carpeta de Fumadores.
